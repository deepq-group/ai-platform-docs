# 2.2 AI viewer

### AI viewer layout

The standard AI viewer has a 2x1 layout, with the raw DICOM image and information on the left, inference results and information on the right. The side bar at the far right contains inference result & calculation (optional), image slider at the bottom will appear when the study contains multiple images.

![AI viewer: Image Classification](../.gitbook/assets/Deeploy-con-2-2-0.jpg)



**Single-Label Classification:**

* Inference visualization: heatmap of the inference result
* Inference result: class name and confidence score

![AI viewer: Single-Label Classification](../.gitbook/assets/Deeploy-con-2-2-1.png)

**Multi-Label Classification:**

* Inference visualization: heatmap of the inference result (can switch between classes with <img src="../.gitbook/assets/con-icon-5.png" alt="" data-size="line">)
* Inference result: class names and confidence score of each class that has conf. score >0.5

![AI viewer: Multi-Label Classification](../.gitbook/assets/Deeploy-con-2-2-2.png)

**Object Detection:**

* Inference visualization: bounding boxes of the inference result (toggle on/off with <img src="../.gitbook/assets/con-icon-5.png" alt="" data-size="line">)
* Inference result: Name, object count & max. object width for each class that appears in the image

<figure><img src="../.gitbook/assets/Deeploy-con-2-2-3.png" alt=""><figcaption><p>AI viewer: Object Detection</p></figcaption></figure>

**Object Segmentation:**

* Inference visualization: object masks of the inference result (toggle on/off with <img src="../.gitbook/assets/con-icon-5.png" alt="" data-size="line">)
* Inference result: Name & total area for each class that appears in the image. (Area calculated in pixels if no available spatial information)

<figure><img src="../.gitbook/assets/Deeploy-con-2-2-4.png" alt=""><figcaption><p>AI viewer: Object Segmentation</p></figcaption></figure>

### User feedback

Users can leave their feedback in the AI viewer: correct/incorrect ; helpful/not helpful.

All feedback from different users can be downloaded via the admin console for further use.
